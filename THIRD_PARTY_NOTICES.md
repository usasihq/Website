### Branding derivative

`assets/branding/usasi-hero.png` is a text-only branding edit generated with the built-in image tool on 2026-09-30. The requested prompt was: replace only “American AI, infrastructure, and innovation.” with “American Super Intelligence, infrastructure, and innovation.” while preserving the scene, large title, palette, composition, and aspect ratio. The original file above remains untouched. Public hero and social-image derivatives are generated from this edited source by `npm run prepare:images`. The artwork remains excluded from the code and content licenses.
