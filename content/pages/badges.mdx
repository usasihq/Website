<h2 id="what">What the badge says</h2>

The badge says that a project or organization has an entry in the USASI catalog, an independent, sourced reference on U.S. AI organizations and U.S.-led open models and tools. Clicking it opens that entry, where every statement cites its source.

It is not an endorsement, a rating, a certification, a safety assessment, or a federal approval. It does not show an openness tier or a license, and it looks the same for every entry. USASI is an independent project and is not a United States government website.

<h2 id="get">Getting the code</h2>

Every organization and open model or tool page has a "Share or cite this page" box near the end. Open "For maintainers" there to copy Markdown for a README or HTML for a website. Both link the badge to that page. Please use the code from your own entry, so the badge leads readers to the right record.

<h2 id="rules">A few rules</h2>

- Use the badge only for the entry it links to.
- If the entry is archived or removed, please remove the badge.
- If something in the entry is wrong, [send a correction](/contribute/#corrections) with a primary source. Corrections never depend on whether a project shows the badge.
- Showing the badge has no effect on whether or how anything is listed. See [how entries are chosen](/methodology/).

Not listed yet? See [how to suggest an entry](/contribute/).

<h2 id="privacy">Privacy</h2>

The badge is a small image file served from this site. When someone views a page that shows it, their browser requests the image from this site's host like any other file. On GitHub, GitHub's own image proxy makes that request instead. USASI keeps no separate record of these requests. See the [privacy page](/privacy/#share).
